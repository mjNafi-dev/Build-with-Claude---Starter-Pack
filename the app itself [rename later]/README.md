# The app goes here

This folder is renamed to the app's name during setup, and the framework project (usually Flutter) is scaffolded inside it.

- One codebase per app. If the chosen framework can't target all OSes from one project, per-OS subfolders are created in here.
- The in-app version constant lives in this codebase and must always match `meta.js` in the hub data.

This README is deleted when the real project is scaffolded.
